# 无忧行客户端与使用教程

想在电脑或手机的其他应用里使用无忧行，需要安装一个兼容的代理客户端。下面保留了全部 18 篇教程，每一篇都包含该工具自己的安装、导入订阅、选择节点和常见问题。

## 按设备选择客户端

先打开[按设备选择客户端](/devices/)。一般建议优先选择同时标为**推荐**和**Jego 当前支持**的工具：

- **推荐**：适合大多数用户优先选择；
- **高级**：功能较多，设置也更复杂；
- **不推荐/已停用**：只供老用户查阅或迁移，不建议新安装；
- **Jego 已不再支持**：不能继续用于新的 Jego 配置。

特别提醒：Jego 已不支持 v2rayN、v2rayNG、Loon 和 OneClick。请按页面给出的替代工具迁移。
