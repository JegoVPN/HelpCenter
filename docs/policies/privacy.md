# Jego 隐私与数据说明

::: info 官方政策
本页用更容易理解的方式介绍 [Jego 官方隐私政策](https://jegocloud.com/policy)。政策自 2026 年 1 月 5 日生效；如果本页与政策原文有差异，以原文为准。
:::

## Jego 会处理哪些信息

注册、登录和购买服务时，Jego 需要处理少量账号与交易信息：

| 信息 | 为什么需要 | 政策中的说明 |
|---|---|---|
| 邮箱 | 登录 | 加密存储于美国 Akamai 基础设施 |
| 密码 | 身份验证 | 哈希后存储于美国 Akamai 基础设施 |
| 订阅状态 | 服务访问 | 加密存储于美国 Akamai 基础设施 |
| 交易 ID | 支付核验 | 加密存储；支付卡或支付账户详情由支付处理方处理 |

政策说明，数据传输使用 HTTPS/TLS，存储的数据会加密，并限制获授权人员访问。Jego 不出售个人数据，也不使用分析、广告、像素或第三方跟踪 Cookie。

政策同时说明，Jego 服务不会访问浏览历史、标签页、Cookie、页面内容、网络请求或文件，也不记录浏览活动、连接时间或位置。这里是在转述官方政策；你另外安装的第三方客户端和访问的网站有各自的隐私规则。

## 浏览器插件权限

官方政策列出四项权限及用途：

| 权限 | 政策说明的用途 |
|---|---|
| `storage` | 在本地保存设置 |
| `proxy` | 通过 Jego 服务器路由流量 |
| `alarms` | 定时更新连接所需的信息 |
| `management` | 检测冲突的扩展 |

这些权限分别用来保存设置、切换代理、保持连接信息更新和识别其他代理扩展。更多解释见[插件权限说明](/guide/plugin-permissions-privacy)。

## 付款和删除账号

- 支付卡或支付账户详情由支付处理方直接处理；Jego 收到用于核对付款的交易 ID。具体处理方和支付方式以结账页为准。
- 政策说明数据存储在美国，服务不面向 13 岁以下用户。
- 用户可登录查看数据，并可在 Account Settings 发起账户删除。遇到安全事件或无法登录时，可以[联系客服](/guide/support)。

订阅服务的安装、导入和更新步骤放在对应的[设备教程](/subscription/#按设备安装)中。
