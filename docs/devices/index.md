# 你的设备应该用哪个无忧行客户端

先找到你的设备和系统，再进入对应指南。设备页会告诉你优先选哪个客户端；工具页则提供从下载、导入订阅到开始连接的完整步骤。

## 先选择设备

| 设备或系统 | 设备指南 |
|---|---|
| 还不确定使用电脑还是手机 | [PC 与手机选择指南](/devices/pc-mobile) |
| Windows | [Windows 指南](/devices/windows) |
| macOS | [Mac 指南](/devices/mac) |
| Linux | [Linux 指南](/devices/linux) |
| Android | [Android 指南](/devices/android) |
| iPhone / iPad | [iOS / iPadOS 指南](/devices/ios) |
| HarmonyOS | [HarmonyOS 指南](/devices/harmony) |
| Apple 账户地区相关问题 | [Apple ID 指南](/devices/us-apple-id) |

## 或者直接查看全部客户端

下面列出帮助中心现有的全部教程。优先选择标为“推荐”且“Jego 当前支持”的工具；高级工具更适合有经验的用户。

<ToolCatalog locale="zh" />

Jego 已不支持 v2rayN、v2rayNG、Loon 和 OneClick，也不再支持已经停止维护的 Clash for Windows 与 Clash for Android。它们的旧教程仍保留，方便已有用户查资料和迁移；新用户直接选择表格中标为“适合大多数用户”的客户端即可。

选好工具后，进入教程完成安装和导入。订阅复制、更新和换设备见[订阅管理](/subscription/management)；出现空列表、更新失败或无法连接时，看[客户端故障排查](/troubleshooting/client)。
