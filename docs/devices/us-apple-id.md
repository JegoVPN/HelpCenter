# 美区 Apple ID 注册教程

部分 iOS/iPadOS 代理工具需要使用非中国大陆区 App Store 下载。如果你没有可用的非大陆区 Apple ID，可以参考本教程注册美区账号。Apple 现在也会把 Apple ID 称为 Apple Account，实际注册和登录时按页面提示操作即可。

## 注册前准备

1. 一个没有注册过 Apple ID 的邮箱，建议使用 Gmail 邮箱；
2. 一台 iPhone 或 iPad；
3. 无忧行开启全局模式，并选择任意美国节点。

## 第一步：创建 Apple ID

1. 打开 [苹果官方网站入口](https://appleid.apple.com/us/)，点击右上角 **创建您的 Apple ID**。（页面语言是中文不影响注册，国家或地区选择正确即可。）

<img src="/images/apple-id-us/apple-id-us-01.png" alt="Apple ID 创建入口">

2. 创建一个新的 Apple ID，国家和地区选择 **美国**。手机号码和邮箱要真实填写，方便接下来的验证；密码要包含大小写字母以及数字。填完后点击 **继续**。

<img src="/images/apple-id-us/apple-id-us-02.png" alt="创建 Apple ID 表单" width="257">

<img src="/images/apple-id-us/apple-id-us-03.png" alt="填写 Apple ID 账号信息" width="259">

<img src="/images/apple-id-us/apple-id-us-04.png" alt="继续创建 Apple ID" width="261">

3. 验证你的电子邮箱，输入收到的邮件验证码，点击 **继续**。

<img src="/images/apple-id-us/apple-id-us-05.png" alt="验证电子邮箱" width="257">

4. 验证你的手机号码，输入验证码，点击 **继续**。

<img src="/images/apple-id-us/apple-id-us-06.png" alt="验证手机号码" width="244">

5. 到这里，美区 Apple ID 账号只完成了第一阶段。接下来还需要在 iOS 设备上验证该账号。

<img src="/images/apple-id-us/apple-id-us-07.png" alt="Apple ID 创建完成">

## 第二步：验证账号

1. 用你的 iOS 设备登录刚注册的美国 Apple ID 账号。账号密码输入正确并点击登录后，一般会出现验证弹窗，点击验证。

::: warning 注意
验证时手机必须处于代理模式，并选择美国节点。
:::

<img src="/images/apple-id-us/apple-id-us-08.png" alt="在 iOS 设备上验证 Apple ID" width="298">

2. 地区仍然选择 **United States**，打开 **Agree to Terms and Conditions** 同意条款和条件，然后点击 **Next** 继续。

<img src="/images/apple-id-us/apple-id-us-09.png" alt="选择 United States 并同意条款" width="257">

3. 接下来会让你选择付款方式。如果没有出现 **None**，通常说明你的手机网络不是美国 IP，需要重新选择美国节点后再试。付款方式选择 **None**。

::: info 说明
美区支持的支付方式通常包括银行卡或信用卡、美区 PayPal、None。大陆发行的外币单币卡、双币卡、全币卡，以及绑定这些卡的美区 PayPal，可能无法用于完成验证，因此这里建议选择 None。
:::

<img src="/images/apple-id-us/apple-id-us-10.png" alt="选择 None 作为付款方式" width="258">

4. 填写账单信息、地址以及电话号码。地址可以搜索“美国个人信息生成”获取；电话号码建议使用你能长期接收验证码的真实号码，避免使用不稳定或已停止服务的接码平台。填写完毕后点击下一步，完成验证。

<img src="/images/apple-id-us/apple-id-us-11.png" alt="填写账单地址信息" width="239">

::: warning 注意
美国 Apple ID 购买应用可能涉及销售税。如果你希望购买付费 app 时税费较低，可以在地址处填入税率较低的州，例如 Oregon（俄勒冈州）、Alaska（阿拉斯加州）、Delaware（特拉华州）、Montana（蒙大拿州）、New Hampshire（新罕布什尔州）等。
:::

5. 至此，美国 Apple ID 注册完成。你可以在美区 App Store 中下载游戏和应用软件，也可以登录美区 iTunes 使用相关内容服务。

## 如何在美区 App Store 购买付费应用？

### 充值礼品卡

国内较方便的方法是购买 iTunes Gift Card 礼品卡，可以从美国苹果官网购买，也可以从亚马逊等第三方平台购买。购买时需要确认礼品卡适用地区为美国。购买礼品卡时通常支持大陆发行的外币单币卡、双币卡以及全币卡付款。

打开美国苹果官网礼品卡购买页面，然后点击购买按钮。

<img src="/images/apple-id-us/apple-id-us-12.png" alt="美国苹果官网礼品卡购买页面">

::: warning 注意
检查页面底部的国家或地区是否为美国。如果不是美国，记得先切换到美国。
:::

<img src="/images/apple-id-us/apple-id-us-13.png" alt="检查苹果官网国家或地区">

然后选择购买方式、金额以及你喜欢的图案。

<img src="/images/apple-id-us/apple-id-us-14.png" alt="选择礼品卡购买方式" width="563">

<img src="/images/apple-id-us/apple-id-us-15.png" alt="选择礼品卡金额" width="563">

<img src="/images/apple-id-us/apple-id-us-16.png" alt="选择礼品卡图案" width="563">

接下来确认自己的订单，然后选择以游客方式购买。

<img src="/images/apple-id-us/apple-id-us-17.png" alt="确认礼品卡订单" width="563">

<img src="/images/apple-id-us/apple-id-us-18.png" alt="以游客身份继续购买" width="563">

然后选择你的付款方式。可选方式通常包括 Apple Card、Visa、Mastercard、AMEX、Discover、UnionPay 以及 PayPal 等。

<img src="/images/apple-id-us/apple-id-us-19.png" alt="选择礼品卡付款方式" width="563">

以信用卡支付为例，需要填写信用卡卡号、有效期以及安全码等信息。

<img src="/images/apple-id-us/apple-id-us-20.png" alt="填写信用卡付款信息" width="416">

最后支付订单即可。购买成功后，礼品卡代码通常会在几个小时内发送到你的邮箱。

### 兑换礼品卡

进入 **App Store**，点击右上角你的 Apple ID 头像，点击 **Redeem Gift Card or Code** 兑换礼品卡或代码，再点击 **You can also enter your code manually** 手动输入代码，即可充值并在美区 App Store 购买付费应用。

::: warning 注意
中国官网购买的充值卡只能在国区 Apple ID 使用，并且充值后通常只能在 App Store 消费。美国官网购买的充值卡充值后，不仅可以在 App Store 消费，也可以在 iTunes Store 等苹果商店消费。
:::
