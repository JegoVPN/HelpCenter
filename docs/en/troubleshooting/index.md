# Jego troubleshooting guide

Choose the symptom that looks closest. Change one setting at a time and test again; the cause is usually quick to find.

## Find the matching symptom

| Symptom | Entry point |
|---|---|
| A website will not open in the browser | [Find out why a website will not open](/en/guide/network-diagnostics#connection-check) |
| The current node fails or feels slow | [Test which nodes are available](/en/guide/network-diagnostics-node-speed) |
| Subscription import/update, empty node list, or client connection fails | [Client troubleshooting](/en/troubleshooting/client) |
| Known browser or site issue | [FAQ](/en/guide/faq) |
| Install or update Jego | [Jego updates and recovery](/en/guide/plugin-maintenance) |
| Account, billing, or security incident | [Contact support](/en/guide/support) using the matching issue category |

## Try these simple checks first

1. Make sure the computer or phone can access the internet without Jego.
2. Note the Jego or client version, operating system, time, and exact error text.
3. Change one item at a time—for example, switch nodes and then test the website.
4. If another VPN or proxy is running, temporarily turn it off.
5. If only one website has a problem, clear data for that site rather than the whole browser.

Keep the system firewall and security software on during testing.

## Before contacting support

Prepare the version, operating system, time, mode or node, exact error text, and the steps that caused the problem.
