When you need human help, open **Ticket** in the Jego Dashboard and submit a ticket. Because of time zones and staffing, we may not reply right away, but we'll reply within 24 hours.

## Follow These 3 Steps to Get Your Issue Solved Fastest

### 1. Check the Guidelines First

Many common issues can be fixed right away by following the step-by-step checks, with no waiting. Open **Guidelines** at the bottom of the Dashboard, or check the [FAQ](/en/guide/faq) and [Network Diagnostics](/en/guide/network-diagnostics) in this help center.

### 2. Submit a Ticket and Describe the Issue Clearly

Click **Ticket** in the Dashboard sidebar to submit a ticket, and tell us:

* Which website or service isn't working
* What message or error you see
* Whether it happens all the time or only sometimes

Attach screenshots if you have them. They help us find the cause faster. See the examples below for browser extension and subscription service issues.

### 3. Wait for Our Reply

Our reply will show up under **Ticket** in the Dashboard and will also be sent to your registered email. You can reply to that email directly to keep talking with support.

## Feedback for Jego Browser Extension

::: info The more specific the information, the faster the resolution!

Detailed information and a specific description of the issue allow us to accurately pinpoint and resolve the problem.
:::

Include when it happened, the operating system and version, browser or client version, Jego mode and node, steps you took, exact error, and the [Connection](/en/guide/network-diagnostics#connection-check) result.

**Ticket Content Reference:**

```
Incident time and timezone: 2026-07-10 14:30 UTC+8
Jego version: full version displayed by the Dashboard
Browser version: full version displayed on the browser About page
Operating system: system name and version
Jego mode: Rules / Global / Off
Network type: home Wi-Fi / managed network / mobile hotspot (no precise address)
Steps: 1. Enable Rules; 2. Open bing.com
Issue Description:
Enabled Jego Rule mode, but accessing bing.com always shows "server not found" (see attached screenshot). Please assist.
```
