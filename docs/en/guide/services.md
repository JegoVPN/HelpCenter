# Jego's Three Versions

In the Jego extension popup, the top-right badge only shows **Free** or **VIP active** — Trial accounts also show **Free** there. To confirm a trial, look for **N days Trial** in the membership area of the popup. Each version differs in website range, node choice, proxy rules, and device support, so read the section that matches the current version.

## Free Version

Register for a Jego account with an email address to start using the Free Version.

The Free Version works directly in Chrome and Edge, but website access is limited. It currently supports selected sites such as Google, Wikipedia, NewBing, ChatGPT, Grok, and Claude.

The Free Version uses the overseas edge network, with nodes and proxy rules preset by Jego.

<img src="/images/jego-v1.5.9/popup-free-on-en.png" alt="Free version interface" width="280" />

## Trial Version

Activate the account from the welcome email to start the three-day Trial.

The Trial is not limited to the Free Version's selected-site list; it can choose from a limited set of nodes and customize proxy rules.

The Trial does not include the computer and phone subscription service.

<img src="/images/jego-v1.5.9/popup-trial-rules-auto-en.png" alt="Trial version interface" width="280" />

## VIP Version

Complete payment to start using the VIP Version.

The VIP Version is also not limited to the Free Version's selected-site list. It can choose from dozens of high-speed nodes worldwide, customize proxy rules, and use the edge network, mainland-optimized routes, mainland transit routes, and IEPL private lines.

VIP also includes subscription service for computers and phones. See [Membership System](/en/membership/benefits) for the full benefits.
