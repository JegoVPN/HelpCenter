# Jego's Three Versions

Open the Jego extension popup to see the current version in the top-right corner. Each version differs in website range, node choice, proxy rules, and device support, so read the section that matches the current version.

## Free Version

The Free Version works directly in Chrome and Edge, but website access is limited. It currently supports selected sites such as Google, Wikipedia, NewBing, ChatGPT, Grok, and Claude.

The Free Version uses the overseas edge network, with nodes and proxy rules preset by Jego. Subscription service for computers and phones is included with VIP.

<img src="/images/jego-v1.5.9/popup-free-on-en.png" alt="Free version interface" width="280" />

## Trial Version

After registering and activating the account from the welcome email, it receives a three-day Trial. The Trial is not limited to the Free Version's selected-site list; it can choose from several nodes, customize proxy rules, and use overseas mainland-optimized routes. Computer and mobile subscription service is available only with VIP.

<img src="/images/jego-v1.5.9/popup-trial-rules-auto-en.png" alt="Trial version interface" width="280" />

## VIP Version

The VIP Version is also not limited to the Free Version's selected-site list. It can choose from dozens of high-speed nodes worldwide, customize proxy rules, and use the overseas edge network, overseas mainland-optimized routes, and private network lines.

VIP also includes subscription service for computers and phones. See [Membership System](/en/membership/benefits) for the full benefits and [How to pay](/en/membership/payment) for payment steps.
