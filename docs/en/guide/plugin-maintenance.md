# Jego updates and recovery

To keep Jego up to date or recheck its status after a browser update, follow this page in order. Confirm the version, select Rules mode and Auto Select again, then use **Diagnostics** to view the current working status.

## Confirm and update the version

1. Enter `chrome://extensions` in Chrome, or `edge://extensions` in Edge.
2. Find Jego on the extensions page and check the current version.
3. Open [Stay Connected](/en/guide/keep-updated) to confirm the latest version and official release links.
4. Update Jego using the same installation method as before, then fully quit and reopen the browser.

For a Chrome Web Store or Edge Add-ons installation, continue updating through the same store. For a manual installation, follow the manual update section on the Stay Connected page.

## Open Jego after updating

After updating, select the mode and node used for everyday browsing:

1. Switch Jego to Off, then back to Rules mode.
2. Set the current node to Auto Select.
3. Fully quit and reopen the browser.
4. Click the Jego icon and confirm that the popup shows Rules mode and the current node.

## Check the current working status

Open **Dashboard** → **Diagnostics**. Check the current mode and node first, then review the connection results for common websites. You can also enter a website to see whether it uses Jego or connects directly. These results show whether the next step is to change the node or adjust Proxy Rules.

See [Diagnostics](/en/guide/network-diagnostics) for the full walkthrough.

## When you choose to reinstall Jego

Use this section only after you decide to reinstall Jego or Support specifically asks you to do so.

1. Note the current version, the original installation source, and any Proxy Rules you added.
2. Find Jego in the extension manager and select **Remove**.
3. Use the [installation guide](/en/guide/installation) to install Jego from the same official source.
4. Sign in, then select Rules mode and Auto Select.

## Get more help

When you need help from Support, share the browser version, Jego version, operating system, and the result shown in **Diagnostics**. See [Contact support](/en/guide/support) for contact options.
