# Copy, import, and update a Jego subscription

A subscription is a private link beginning with `http://` or `https://`. A client uses it to download your node list. Menus vary between clients, so this page covers the common process; open the matching [client guide](/en/tool/) for exact buttons.

## Copy and import for the first time

1. Choose a client from the [device page](/en/devices/) and install it.
2. Sign in to the Jego Control Panel and open **Mobile Proxy**.
3. Choose the subscription type required by the client guide, then copy it.
4. Move directly to the client and paste it into **Add subscription**, **New profile**, or a similar item.
5. Save, then run **Update**, **Sync**, or **Refresh** once.
6. When nodes appear, choose one and turn on the connection.
7. Open an ordinary website to confirm it works.

Use the complete URL generated by the Control Panel and import it directly into a trusted client. Choose the subscription type named by the client guide.

## Update nodes later

When Jego's nodes change, or after renewing membership, find the existing subscription in the client and choose **Update**, **Sync**, or **Refresh**. The existing client settings can stay in place.

If the client supports automatic updates, its own guide will show where to enable them.

## Common problems

| Symptom | Next step |
|---|---|
| No nodes appear after pasting | Save and update once, then confirm you chose the right subscription type |
| The client reports an invalid format | Copy the complete link again from the Jego Control Panel |
| Update fails or the link is invalid | Check membership and network status, then copy it once again |
| Nodes appear but cannot connect | Choose another node, then use [client troubleshooting](/en/troubleshooting/client) |
| Only one website fails | Check the client's mode or rules; the subscription itself may still be fine |

## Move to another device or client

Install a currently supported client on the new device, then copy the subscription directly from the Jego Control Panel. Confirm the new device works before clearing the old configuration. Transfer complete configurations only between your own trusted devices.

## If the subscription URL leaks

If the URL was sent to the wrong person, posted in a group, or uploaded to an unfamiliar site:

1. Stop forwarding or screenshotting it.
2. Note roughly when it happened.
3. Ask [Support](/en/guide/support) or use the Control Panel to replace the URL.
4. Delete the old URL from every client and import the new one.

Support only needs a screenshot or the exact error text from the client.
