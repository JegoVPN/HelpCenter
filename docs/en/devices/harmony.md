# HarmonyOS Proxy Guide

HarmonyOS (English: HarmonyOS, abbreviated as HMOS, development codename Ark, official name is Huawei Terminal HarmonyOS Intelligent Device Operating System Software)

Jego members can use a compatible proxy client on HarmonyOS. HarmonyOS NEXT and older HarmonyOS releases use different tools, so check the system version before following the matching install and import guide below.

<div class="tip custom-block" style="padding-top: 8px">

Jego subscription service mobile panel: <https://jego.us>

</div>

## <img src="/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2FhUBqYs4CpmMcueAi690m_2FHMOS_Logo_Icon_1.svg" width="38" height="28" alt="HarmonyOS icon"> HarmonyOS 5 proxy clients

For HarmonyOS 5 / NEXT, the **ClashBox** guide is currently available. The client is still experimental and requires a Huawei developer account or a non-mainland Huawei AppGallery account for installation.

### Experimental client

<div class="client-guide-link"><img src="/images/clashbox-logo-new.png" width="26" height="26" alt="ClashBox icon"><a href="/en/subscription/clients/clashbox">ClashBox</a></div>

ClashBox / ClashNEXT is a HarmonyOS NEXT (OpenHarmony) proxy client based on the Mihomo (formerly ClashMeta) core. If the installation requirements above are available, open the complete guide to continue.

## <img src="/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2FhUBqYs4CpmMcueAi690m_2FHMOS_Logo_Icon_1.svg" width="38" height="28" alt="HarmonyOS icon"> HarmonyOS 1.0–4.3 proxy clients

These releases can run compatible Android clients. New users can start with **FlClash** or **sing-box for Android**.

### Recommended clients

<div class="client-guide-link"><img src="/images/android_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2Fu2sHeQjHJurcgVhJB1zO_2Ficon_3.png" width="26" height="26" alt="FlClash icon"><a href="/en/subscription/clients/flclash">FlClash</a></div>

FlClash is an easy-to-use multi-platform proxy client. Its complete guide covers installation, subscription import, and connection.

<div class="client-guide-link"><img src="/images/android_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2FX6LBfzRlMdWyQVvPC9eg_2Fimage_2.png" width="26" height="26" alt="sing-box icon"><a href="/en/subscription/clients/sing-boxforandroid">sing-box for Android</a></div>

sing-box for Android is an open-source Android client. Open the complete guide for its installation and subscription-import steps.
