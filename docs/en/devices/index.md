Jego no longer supports v2rayN, v2rayNG, Loon, or OneClick. It also no longer supports the discontinued Clash for Windows and Clash for Android clients. Their original guides remain for existing users and migration help. New users can go straight to a client marked **Good for most users** in the table.

After choosing a tool, follow its guide to install and import. See [Subscription Management](/en/subscription/management) for copying, updating, or moving a subscription. Use [Client troubleshooting](/en/troubleshooting/client) for empty lists, failed updates, or connection problems.
