# Jego clients and setup guides

To use Jego in other apps on a computer or phone, install a compatible proxy client. All 18 existing tutorials remain available below. Each guide includes its own installation, subscription import, node selection, connection, and troubleshooting steps.

## Choose by device

Start with [Choose by device](/en/devices/). In general, choose a tool marked both **Recommended** and **Supported by Jego**:

- **Recommended:** a good first choice for most users;
- **Advanced:** more features and more setup;
- **Not recommended/Discontinued:** kept for existing users or migration, not for a new install;
- **No longer supported by Jego:** cannot be used for a new Jego setup.

Jego no longer supports v2rayN, v2rayNG, Loon, or OneClick. Follow the replacement links on those pages.
