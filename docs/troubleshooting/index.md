# 无忧行故障排查指南

先找到最接近的现象。每次只改一个设置并重新测试，通常很快就能找到真正原因。

## 你遇到哪种问题

| 症状 | 入口 |
|---|---|
| 浏览器里的网站打不开 | [检查网站为什么打不开](/guide/network-diagnostics#connection-check) |
| 当前节点连不上或很慢 | [测试哪些节点能用](/guide/network-diagnostics-node-speed) |
| 订阅导入、更新、空列表或客户端连接失败 | [客户端出问题怎么办](/troubleshooting/client) |
| 已知的浏览器/站点问题 | [常见问题](/guide/faq) |
| 安装或更新插件 | [插件更新与恢复](/guide/plugin-maintenance) |
| 账户、支付或安全事件 | [联系支持](/guide/support)，使用对应问题类别 |

## 先做这几个简单检查

1. 确认电脑或手机本身能正常上网。
2. 记下无忧行或客户端版本、系统、发生时间和完整错误提示。
3. 一次只改一个设置，例如先换节点，再测试网站。
4. 如果同时开着其他 VPN 或代理，暂时停用它们再试。
5. 只有一个网站异常时，只清理这个网站的数据，其他网站的登录状态可以继续保留。

测试期间保持系统防火墙和安全软件正常开启。

## 联系支持前

准备版本、操作系统、发生时间、当前模式或节点、页面上的错误文字，以及“做了什么以后出现问题”。
