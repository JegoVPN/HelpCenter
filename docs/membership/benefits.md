# 会员体系

升级会员后，可以同时享受浏览器插件的高级节点和电脑、手机可用的订阅节点，是无忧行更完整的使用方式。

## 付费会员有哪些权益

1. **更多高质量浏览器节点**：网络拥堵或某条线路不稳定时，有更多线路可以选择，访问全球网站更顺畅。
2. **电脑和手机也能使用**：会员包含无忧行订阅节点服务，可以按教程添加到 Windows、macOS、Linux、Android、iPhone 和 iPad 的兼容客户端。
3. **一个账号集中管理**：在控制面板查看会员状态、到期时间、订阅节点、订单和客服入口。

想先了解具体怎么用，可以看[电脑和手机使用指南](/subscription/)。

## 购买前核对权益

1. 打开无忧行插件，点击右上角的免费版/会员状态，或进入 **控制面板 → 开通会员**；
2. 选择套餐，查看有效期、价格、浏览器节点和订阅服务说明；
3. 查看订单币种、实际支付金额和续费方式，确认后再付款；
4. 需要在电脑或手机应用中使用订阅时，从[按设备安装](/subscription/#按设备安装)进入对应教程。

::: tip 购买前看清页面
套餐和活动可能调整，当前购买页面显示的信息最准确。如果控制面板和结算页内容不一致，可以联系客服确认。
:::

## 购买后核对生效状态

- 在控制面板确认会员状态、到期时间和可用入口是否更新；
- 如订单显示成功但权益未显示，先刷新页面、退出后重新登录，并确认使用的是付款账户；
- 续费后的到期时间和会员等级以账户页面更新结果为准；
- 如需支持，请提供订单时间、订单状态和页面截图。

## 免费版和会员版的区别

免费版适合先在浏览器里体验无忧行；会员版提供更多浏览器节点和电脑、手机订阅服务。无论哪种方案，实际速度都会受到本地网络、节点和目标网站影响。网站打不开时，可以先用[连接检测](/guide/network-diagnostics#connection-check)判断问题出在哪里。

## 套餐发生变化时

续费前先看一眼当前到期时间，再阅读新订单的生效说明。付款完成后保留订单确认，并回到控制面板核对会员状态、订阅入口和新的到期时间。长时间没有更新时，退出后重新登录；页面仍未更新时，带上订单信息联系客服确认。
