# 会员体系

## 付费会员的权益

1. 遇到网络屏蔽、封禁或故障时，无忧行团队会**优先保障付费会员**的服务。
2. 可以使用无忧行插件里更多、更快、更稳定的网络节点。
3. 会员包含无忧行订阅服务，可以在电脑和手机的兼容客户端中使用。具体方法见[电脑和手机使用指南](/subscription/)。

::: warning 免费服务说明
免费线路使用人数较多，线路可用性和负载可能出现波动。无忧行团队会持续维护免费服务。
:::

## 付费会员的等级

| 月卡 | 季卡 | 半年卡 | 年卡 |
| --- | --- | --- | --- |
| <span style="color:green;">`31天`</span>的 VIP 时长 | <span style="color:green;">`93天`</span>的 VIP 时长 | <span style="color:green;">`186天`</span>的 VIP 时长 | <span style="color:green;">`366天`</span>的 VIP 时长 |
| VIP 等级 +<span style="color:green;">`1`</span> | VIP 等级 +<span style="color:green;">`3`</span> | VIP 等级 +<span style="color:green;">`6`</span> | VIP 等级 +<span style="color:green;">`12`</span> |

::: info VIP 规则说明

### VIP 时长是叠加的

购买的 VIP 时长会直接累加到账号上。

- 连续购买 2 张月卡 → VIP 时长 = 31 + 31 = 62 天
- VIP 还剩 3 天时购买月卡 → VIP 时长 = 31 + 3 = 34 天

### VIP 等级是累加的

每次购买，等级会增加对应的级数：

| 月卡 | 季卡 | 半年卡 | 年卡 |
| :---: | :---: | :---: | :---: |
| +1 级 | +3 级 | +6 级 | +12 级 |

**举例**：

- 新用户买月卡 → 等级 = 0 + 1 = **1**
- 再买一张月卡 → 等级 = 1 + 1 = **2**
- 再买一张年卡 → 等级 = 2 + 12 = **14**

:::

## VIP 等级的作用

等级越高，可以使用的高速节点越多。部分高速节点设有等级门槛。
