# 如何支付

::: info 货币说明
结算页会显示当前商品币种、实际扣款金额和可用支付方式。汇率、手续费和可用渠道可能因地区、发卡行和支付服务商而变化，请在确认付款前核对页面。
:::

## 支付路径：

打开**无忧行**插件，点击**控制面板**，然后点击左侧导航栏里**开通会员**，选择你需要购买的会员即可开始支付。

付款前建议按这个顺序检查：

1. 确认登录的是准备购买会员的无忧行账号；
2. 选择套餐，查看有效期、币种和应付金额；
3. 选择结算页实际显示的支付方式；
4. 跳转到收银台后，再核对一次商户、金额和币种，然后完成付款。

## 付款后查看支付记录

付款完成后，打开**控制面板 → 支付记录**，查看是否能查询到本次订单。

## 支付渠道：

无忧行会根据账号和地区显示当前可用的支付方式。下面是你可能在结算页看到的入口；页面显示哪个，就按哪个方式付款。

### <img src="/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2F24s06IHgl9yYTX5MypkX_2Fimage_3.png" width="104" height="33" alt="银联支付图标"> 银联支付

如结算页显示银联，可按页面提示进入对应收银台。支持卡种、扣款币种、汇率和手续费以收银台及发卡行最终信息为准。

中国大陆发行的银行卡如果没有开通境外或线上交易，可能会被发卡行拒绝。遇到这种情况，请拨打卡片背面的官方客服电话确认，等交易状态明确后再操作。

### <img src="/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2F6dqhoWXM9ypD6HfwNX3X_2Fimage_1.png" width="104" height="33" alt="支付宝图标"> 支付宝

如结算页显示支付宝，按收银台提示核对付款账户、币种和金额后完成支付。实际可用性以支付服务商为准。

页面会跳转到支付宝收银台；付款后请等待它返回无忧行，或者手动回到控制面板查看支付记录。

### <img src="/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2FP1bfW4Ha7dtRtCBM1TsO_2Fimage_2.png" width="104" height="33" alt="微信支付图标"> 微信支付

如结算页显示微信支付，按收银台提示核对付款账户、币种和金额后完成支付。实际可用性以支付服务商为准。

使用扫码或微信内确认时，先核对金额和收款页面，并把付款二维码只保留在本次付款设备上。

### <img src="/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2FNYpn2vq3mOCdLVmJFJxU_2Fimage_3.png" width="104" height="33" alt="加密货币图标"> 加密货币支付

只有结算页显示加密货币入口时才使用。务必核对币种、网络、地址、金额和到账要求；链上转账通常难以撤回，请只使用本次收银台生成的地址。

币种相同但链不相同也可能造成资产丢失，所以请同时检查代币名称和网络名称，并只使用本次收银台生成的信息。

### <img src="/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2F5872Aul15csYNh36x2ea_2Fimage_1.png" width="104" height="33" alt="PayPal图标"> PayPal

如结算页显示 PayPal，可进入其收银台核对账户、币种、金额和可选资金来源。是否支持免登录银行卡或特定卡种以 PayPal 当前页面为准。

你可以使用 PayPal 账号内的资金来源；收银台如果提供银行卡付款，也可以按当页提示操作。

### <img src="/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2F6ALLasfYTQHuuqkOWP85_2Fimage_2.png" width="104" height="33" alt="信用卡图标"> 信用卡

如结算页显示信用卡或数字钱包，可按其安全收银台提示操作。支持的卡组织、钱包、币种、手续费和换汇由当前收银台与发卡行决定。

输入卡片信息时只在支付服务商的安全收银台完成。无忧行客服不会向你索要完整卡号、安全码、短信验证码或 Apple Pay / Google Pay 的验证信息。

## 常见问题

### 支付被发卡行拒绝

先确认订单金额、币种、账单资料和验证步骤是否正确，并等待当前交易状态明确。拒付原因由发卡行或支付服务商决定；请使用卡片背面的官方联系方式核对跨境、线上交易或风控状态。

### 发票与收据

先在**无忧行控制面板 → 支付记录**查看当前订单有没有发票或收据下载入口。如果用于报销，还要向所在组织的财务部门确认需要什么格式和抬头。

订单页面没有所需文件时，请按[支持说明](/guide/support)提供订单时间和遮盖部分内容的订单号，询问当前订单能否开具。

支付记录通常只展示最近的成功订单；需要查更早的订单时，可以向客服提供注册邮箱的脱敏形式和大概付款时间。邮件里没有找到相关文件，也请检查垃圾邮件文件夹。

### 支付状态暂时不明确

如果付款页面关闭、超时或返回控制面板后状态不清楚，先在银行或支付服务商中确认是否存在已完成或待处理交易，再刷新**支付记录**。等当前订单状态明确后再继续。短信验证码、完整卡号、安全码、钱包助记词和交易私钥只保留在自己的付款设备上。若发生重复扣款或金额不符，保存脱敏订单页、交易时间、币种和支付服务商参考号，再分别联系官方支持与发卡行。
