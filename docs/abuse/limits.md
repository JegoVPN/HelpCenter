# 流量限制

## 无忧行浏览器插件

电脑浏览器上的无忧行插件目前<span style="color:orange;">**没有流量限制**</span>。为了不影响其他用户，请不要长时间占用超大流量。

## 无忧行订阅服务

无忧行订阅服务<span style="color:orange;">**每月有流量限制**</span>。

想看还剩多少流量：打开 **控制面板 → 订阅节点**，查看页面上的**本月剩余流量**。如果显示负数，说明这个月的流量已经用完。

## 流量用完后的状态和恢复

下面两种情况都会重新获得一个完整的流量包：

1. **每月 1 号自动恢复**：进入新的月份后，流量额度会自动补满。
2. **续费或升级后立即恢复**：完成付款后，流量额度会马上补满。

付款成功后，回到控制面板查看会员状态和本月剩余流量。
