# 无忧行订阅复制、导入和更新指南

订阅地址是一条以 `http://` 或 `https://` 开头的私密链接。客户端通过它下载你的节点列表。每个客户端的菜单名称不同，所以本页讲共通步骤；具体按钮请打开对应的[工具教程](/tool/)。

## 第一次复制和导入

1. 先从[设备页](/devices/)选好客户端并完成安装。
2. 登录无忧行控制面板，打开**订阅节点**。
3. 按客户端教程选择对应的订阅类型，然后点击复制。
4. 立即切换到客户端，在“添加订阅”“新建配置”或类似入口粘贴。
5. 保存后执行一次**更新**、**同步**或**刷新**。
6. 节点列表出现后，选择一个节点并打开连接。
7. 用一个普通网站测试是否成功。

直接使用控制面板生成的完整订阅地址。某个教程要求哪种类型，就使用对应类型，并只导入受信任的客户端。

## 更新节点

无忧行的节点有变化，或者你刚续费后，可以在客户端里找到当前订阅，点击**更新**、**同步**或**刷新**。不需要删除账号，也不用清空整个应用。

如果客户端支持自动更新，可以按它的教程设置更新间隔；是否支持、菜单在哪里，以该工具页面为准。

## 常见问题

| 你看到的情况 | 先这样处理 |
|---|---|
| 粘贴后没有任何节点 | 保存后手动更新一次，并确认订阅类型选对了 |
| 提示格式错误 | 从无忧行控制面板重新复制完整链接 |
| 更新失败或链接失效 | 检查会员是否到期、网络是否正常，再重新复制一次 |
| 有节点但连不上 | 选择另一个节点，并看[客户端故障排查](/troubleshooting/client) |
| 只有一个网站打不开 | 检查客户端模式或规则，订阅本身不一定失效 |

## 换手机、换电脑或换客户端

在新设备上先安装当前支持的客户端，再直接从无忧行控制面板复制订阅。新设备确认能用后，再清理旧设备中的配置。完整配置只通过自己的受信任设备转移。

## 订阅地址需要更换时

如果链接发错人、贴到群聊或上传到陌生网站，请把它当作已经泄露：

1. 停止继续转发或截图。
2. 记下大概发生时间。
3. 通过控制面板或[客服](/guide/support)申请更换订阅地址。
4. 在所有客户端中删除旧链接，导入新链接。

联系客服时不需要把旧订阅地址再次发出来。
