# 在电脑和手机上使用无忧行订阅

无忧行浏览器插件只负责 Chrome 和 Edge 里的网页。如果你是会员，还可以获取一条订阅地址，把无忧行节点添加到电脑或手机上的兼容客户端中，让其他应用也能使用代理。

## 第一次使用，按这三步走

1. [选择你的设备](/devices/)，找到当前推荐的客户端。
2. 打开对应的[客户端完整教程](/tool/)，先安装好应用。
3. 在无忧行控制面板复制订阅地址，按教程导入、选择节点并打开连接。

不知道“订阅”是什么也没关系：可以把它理解成一条私密链接，客户端通过它取得你的节点列表。

## 订阅服务使用步骤

| 你的情况 | 从这里开始 |

| 已经选好客户端，想看安装和导入步骤 | [工具与客户端教程](/tool/) |
| 想复制、更新、换设备或处理订阅失效 | [订阅怎么复制和更新](/subscription/management) |

## 妥善保管订阅地址

订阅地址相当于一把个人钥匙，拿到它的人可能可以读取其中的节点配置。请把它保存在自己的设备和受信任客户端中，截图时完整遮住。

如果订阅地址发错了人或出现在公开位置，马上停止转发，并通过无忧行控制面板或[客服](/guide/support)申请更换。换好后，记得在所有客户端里更新。

::: warning 不再支持的客户端
Jego 已不支持 v2rayN、v2rayNG、Loon 和 OneClick。原教程会继续保留给老用户查阅，但新安装请按设备页选择当前支持的工具。
:::
