# 如何注册

## 注册与登录

1. 点击浏览器上无忧行的小图标，会弹出一个加载中的小窗口：

<img src="/images/jego-v1.5.9/popup-loading.png" alt="加载界面" width="280">

2. 加载完毕后，会出现下图的登录以及注册界面：

<img src="/images/jego-v1.5.9/popup-login-zh.png" alt="登录注册界面" width="280">

* **已注册的**用户可以直接输入邮箱、密码，点击`账户登录`按钮后即可享受无忧行的服务；
* **未注册的**用户点击下方`创建账户`入口，根据提示即可轻松完成无忧行的账户注册。

## 忘记密码

**1、登出状态忘记密码：**

点开无忧行弹窗界面，点击`忘记密码`，按照页面里提示输入注册无忧行的邮箱地址，然后去邮箱里按照邮件提示操作即可重置密码。

<img src="/images/jego-v1.5.9/popup-forgot-password-zh.png" alt="忘记密码界面" width="560">

**2、登录状态忘记密码：**

进入无忧行 `控制面板 - 账户管理` 页面，在修改密码页面最下方能找到`忘记密码`的入口（如下图所示），点击后输入无忧行账户的邮箱地址，然后去邮箱里按照邮件提示操作即可重置密码。

![账户管理忘记密码](/images/jego-v1.5.9/dashboard-account-forgot-password-zh.png)
