# 联系客服

## 联系方式

如需人工协助，请在无忧行控制面板打开**联系客服**提交工单。受时差和客服排班影响，我们不一定能马上回复，但会在 24 小时内回复你。

## 照这 3 步来，问题解决得最快

### 1. 先看使用指南

很多常见问题按使用指南里的步骤检查就能马上解决，不用等待。可以打开控制面板底部的**使用指南**，或者在帮助中心查看[常见问题](/guide/faq)和[网络诊断](/guide/network-diagnostics)。

### 2. 提交工单，把问题说清楚

在控制面板左栏点击**联系客服**提交工单，写清楚这几件事：

* 哪个网站或服务用不了
* 看到了什么提示或报错
* 一直这样，还是偶尔这样

有截图就一起附上，我们能更快找到原因。下方有插件和订阅服务两类问题的写法参考。

### 3. 等我们回复

回复会出现在控制面板的**联系客服**里，同时发到你的注册邮箱。直接回复那封邮件，也能接着和客服沟通。

## 无忧行插件问题反馈

::: info 提供的信息越详细，问题解决越迅速！

详细的基本情况描述和具体的问题说明，有助于我们精准定位并快速解决你的问题。
:::

建议写清楚：什么时候发生、使用什么系统和版本、当前模式和节点、做了哪些操作、看到什么错误，以及[连接检测](/guide/network-diagnostics#connection-check)的结果。

**工单内容参考：**

```
发生时间与时区：2026-07-10 14:30 UTC+8
无忧行版本：控制面板显示的版本
浏览器版本：浏览器“关于”页面显示的完整版本
操作系统：系统名称与版本
无忧行模式：规则 / 全局 / 关闭
网络类型：家庭 Wi-Fi / 公司网络 / 手机热点（写网络类型即可）
复现步骤：1. 开启规则模式；2. 访问 bing.com
问题描述：
开启无忧行规则模式后，访问 bing.com 一直显示无法找到服务器（见截图），请求协助解决。
```

## 无忧行订阅服务问题反馈

**工单内容参考：**

```
发生时间与时区：2026-07-10 14:30 UTC+8
操作系统：系统名称与版本
客户端软件及版本：客户端“关于”页面显示的完整版本
网络类型：家庭 Wi-Fi / 公司网络 / 手机热点
复现步骤：1. 更新订阅；2. 选择节点；3. 发起连接
问题描述：
在 FlClash 中所有服务器节点均显示超时，请协助解决。
```

**截图参考：**

![遇到具体问题的详细截图](/images/Catch(11-25-17-58-37).jpg)

:::
