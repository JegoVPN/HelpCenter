# 联系客服

## 联系方式

<h3><svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" fill="currentColor" style="display:inline;vertical-align:middle" viewBox="0 0 16 16"><path d="M0 7.76C0 3.301 3.493 0 8 0s8 3.301 8 7.76-3.493 7.76-8 7.76c-.81 0-1.586-.107-2.316-.307a.64.64 0 0 0-.427.03l-1.588.702a.64.64 0 0 1-.898-.566l-.044-1.423a.64.64 0 0 0-.215-.456C.956 12.108 0 10.092 0 7.76m5.546-1.459-2.35 3.728c-.225.358.214.761.551.506l2.525-1.916a.48.48 0 0 1 .578-.002l1.869 1.402a1.2 1.2 0 0 0 1.735-.32l2.35-3.728c.226-.358-.214-.761-.551-.506L9.728 7.381a.48.48 0 0 1-.578.002L7.281 5.98a1.2 1.2 0 0 0-1.735.32z"/></svg> 在线客服反馈系统</h3>

如需人工协助，可以在无忧行控制面板打开**联系客服**并提交问题。客服受时区和排班影响，无法保证立即回复；官方说明是留言会在 24 小时内得到答复。

::: tip 推荐
建议使用**无忧行控制面板**中的「联系客服」功能，获得更快速的响应体验。
:::

## 无忧行插件问题反馈

::: info 提供的信息越详细，问题解决越迅速！

详细的基本情况描述和具体的问题说明，有助于我们精准定位并快速解决你的问题。
:::

建议写清楚：什么时候发生、使用什么系统和版本、当前模式和节点、做了哪些操作、看到什么错误，以及[连接检测](/guide/network-diagnostics#connection-check)的结果。

**邮件标题参考：**

```
无忧行浏览器插件：访问 bing.com 提示无法找到服务器
```

**邮件内容参考：**

```
发生时间与时区：2026-07-10 14:30 UTC+8
注册邮箱：name@example.com
无忧行版本：控制面板显示的版本
浏览器版本：浏览器“关于”页面显示的完整版本
操作系统：系统名称与版本
无忧行模式：规则 / 全局 / 关闭
网络类型：家庭 Wi-Fi / 公司网络 / 手机热点（写网络类型即可）
复现步骤：1. 开启规则模式；2. 访问 bing.com
问题描述：
开启无忧行规则模式后，访问 bing.com 显示无法找到服务器（见附件截图），请求协助解决。
```

**附件请带上具体问题截图（参考下图）：**

## 无忧行订阅服务问题反馈

**邮件标题参考：**

```
无忧行订阅服务：所有节点显示超时错误
```

**邮件内容参考：**

```
发生时间与时区：2026-07-10 14:30 UTC+8
注册邮箱：name@example.com
操作系统：系统名称与版本
客户端软件及版本：客户端“关于”页面显示的完整版本
网络类型：家庭 Wi-Fi / 公司网络 / 手机热点
复现步骤：1. 更新订阅；2. 选择节点；3. 发起连接
问题描述：
在 FlClash 中所有服务器节点均显示超时，请协助解决。
```

**附件请带上具体问题截图（参考下图）：**

## 💔 无效反馈

![无具体问题的描述、截图等有效信息](/images/image_spaces_2FtaiByLw8cj0IZKJTlaiM_2Fuploads_2Fbdg94Dg1RfBdLyc4L8EI_2Fimage_1.png)

如上图所示，仅发送“有问题”而无具体描述或截图的邮件属于**无效反馈**。此类反馈因缺乏必要信息，我们无法有效地为你提供帮助。
