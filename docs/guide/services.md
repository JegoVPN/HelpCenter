# 服务详解

无忧行提供免费版、限时体验和付费会员。登录后，弹窗右上角会显示你当前的状态；体验或会员用户还能看到剩余天数或到期时间。

## 三种服务怎么选

| 服务 | 适用场景 | 主要区别 |
|---|---|---|
| 免费版 | 先在 Chrome 或 Edge 里体验无忧行 | 使用账号当前提供的免费浏览器线路 |
| 限时体验 | 刚注册并完成激活的用户 | 在体验期内试用更多浏览器节点和功能；具体时长以弹窗为准 |
| 付费会员 | 经常使用，或还想在电脑和手机其他应用里使用 | 解锁更多高质量浏览器节点，并提供无忧行订阅服务 |

模式、节点和会员入口会按账号状态显示。付款前可以在购买页面直接核对套餐、有效期、金额和包含的服务。

## 免费版本

弹窗显示“免费版”时，你正在使用无忧行当前提供的免费服务。选择可用模式和节点后即可开始浏览。

<img src="/images/jego-v1.5.9/popup-free-on-zh.png" alt="免费版本界面" width="280">

## 限时体验

::: info 激活说明
注册后请打开无忧行发送的欢迎邮件，点击其中的激活链接。成功激活后，如果账号获得限时体验，弹窗会显示体验状态和剩余时间。
:::

体验期间可以试用账号当前开放的更多节点和模式。到期时间以弹窗显示为准。

<img src="/images/jego-v1.5.9/popup-trial-rules-auto-zh.png" alt="限时体验界面" width="280">

## 付费服务

付费会员可以使用更多高质量浏览器节点，还能获取在电脑和手机客户端中使用的订阅节点。付款成功后，弹窗会显示会员状态和到期时间；如果没有及时更新，重新登录一次，再按支付记录确认当前订单状态。
