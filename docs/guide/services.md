# 无忧行的三个版本

打开无忧行插件弹窗，右上角可以看到当前版本。对照下面的说明，就能知道这个版本可以在哪里使用、包含哪些功能。

## 免费版

免费版可以直接在 Chrome 和 Edge 浏览器中使用。打开插件，选择页面上当前可用的模式和线路，就可以开始访问网页。

<img src="/images/jego-v1.5.9/popup-free-on-zh.png" alt="免费版本界面" width="280">

## 体验版

注册并通过欢迎邮件激活后，如果账号获得体验版，插件弹窗会显示剩余时间。体验期间可以试用更多浏览器模式和线路。

<img src="/images/jego-v1.5.9/popup-trial-rules-auto-zh.png" alt="限时体验界面" width="280">

## 会员版

会员版适合经常使用，或者还需要在电脑软件和手机应用中使用无忧行。它提供更多浏览器线路，并包含电脑和手机可用的订阅服务。完整权益见[会员体系](/membership/benefits)，付款步骤见[如何支付](/membership/payment)。
