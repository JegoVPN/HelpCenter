# 无忧行的三个版本

打开无忧行插件弹窗，右上角徽章只区分**免费版**和**VIP 已激活**两种，体验版右上角同样显示**免费版**；是否在体验期，看弹窗下方会员区是否显示**N 天体验**。每个版本在网站范围、节点、代理策略和设备支持上都有区别，按当前版本查看对应说明即可。

## 免费版

使用邮箱注册无忧行账号后，即可使用免费版。

免费版可以直接在 Chrome 和 Edge 浏览器中使用，但可访问的网站有限，目前主要支持 Google、Wikipedia、NewBing、ChatGPT、Grok、Claude 等指定网站。

免费版使用境外边缘网络，节点和代理策略由无忧行预先设置。

<img src="/images/jego-v1.5.9/popup-free-on-zh.png" alt="免费版本界面" width="280">

## 体验版

通过欢迎邮件激活账号后，即可使用三天体验版。

体验版的网站范围不受免费版指定名单限制，可以从有限的几个节点中选择并自定义代理策略。

体验版不包含电脑和手机订阅服务。

<img src="/images/jego-v1.5.9/popup-trial-rules-auto-zh.png" alt="限时体验界面" width="280">

## 会员版

完成付费后，即可使用会员版。

会员版的网站范围同样不受免费版指定名单限制，可以选择全球几十个高速节点、自定义代理策略，并使用边缘网络、大陆优化线路、大陆中转线路和 IEPL 内网专线。

会员还包含电脑和手机订阅服务。完整权益见[会员体系](/membership/benefits)。
