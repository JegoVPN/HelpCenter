# 常见问题

### AI 网站的线路选择

并不是每个连接都能使用每项 AI 产品。若当前订阅显示 `🤖 ChatGPT Group` 或插件显示 `[AI]` 标注，可把它作为候选节点提示，再用实际目标验证。规则模式和全局模式可以用来对比代理规则；模式或节点名称都不保证第三方账户资格与持续可用。

### Gemini、ChatGPT、Claude 等网站无法连接

按下面的顺序检查本地网络和浏览器，每完成一步就重新打开网站试一次：

 **网络环境**
  - **核对 DNS**：如本地解析异常，可按系统或路由器说明测试公共 DNS。示例端点与加密 DNS（DoH/DoT）的限制见[加密 DNS 指南](/guide/encrypted-dns)；本页不声称某个解析器固定最快或绝对安全。
  - **清理DNS缓存**：`Win+R` 输入 `CMD` 回车，再执行 `ipconfig /flushdns`。
  - **暂时退出其他代理软件**，如网易 UU、讯飞游戏加速器、V2rayN、Clash，先让无忧行单独工作
  - 打开 `系统设置`->`网络和Internet`->`代理` ，设置：
    - 自动检测设置：关闭
    - 使用设置脚本：关闭
    - 使用代理服务器：关闭

 **浏览器环境**
  - 升级浏览器至最新版本；如需清理数据，只清理发生问题站点的 Cookies 和缓存，再重启浏览器
  - 升级无忧行至[最新版本](/guide/keep-updated)，测试时只保留无忧行处于启用状态
  - 将无忧行设置为规则模式（免费为开启）
  - 重启浏览器


> 能访问New Bing或者ChatGPT之后，就可以尝试逐个开启其他插件或者软件了，目的是排查插件之间的相互影响。

### Google、ChatGPT 显示的位置与节点地区不同

**现象原因：**
Google、OpenAI 等平台会综合参考 IP、Cookies、浏览器缓存、账号状态和设备信息，所以页面显示的位置可能与节点名称不同。使用同一个网站时保持节点稳定，更容易得到一致的结果。

如果普通窗口保存过旧的位置数据，切换节点后平台仍可能继续读取这些信息。下面用无痕窗口做一次对照，就能分清是浏览器数据还是当前连接。

**推荐阅读：** [了解和管理 Google 搜索时的位置信息](https://support.google.com/websearch/answer/179386?hl=zh-Hans)

**排查思路：用无痕模式做一次"纯净测试"**

无痕窗口不会读取普通窗口的大部分 Cookies 和缓存，很适合做一次简单对照。具体步骤如下：

 - **第一步，完全退出浏览器。** 重新打开时会建立一段新的浏览器会话。
 - **第二步，打开无痕 / 隐私模式窗口。** Windows 下快捷键一般是 `Ctrl + Shift + N`（Edge 是 `Ctrl + Shift + P`），Mac 下是 `Cmd + Shift + N`。
 - **第三步，允许无忧行在无痕窗口运行。** 打开扩展管理页（Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`），找到**无忧行**，点击“详情”，再打开“**在无痕模式下运行 / Allow in InPrivate**”。
 - **第四步，在无痕窗口里打开无忧行，切到全局模式并选择一个节点。** 测试期间保持这个节点不变。
 - **第五步，打开 [IP111.cn](https://ip111.cn) 查看当前出口。** 显示位置与所选节点一致，说明当前连接已经生效。
 - **第六步，这时再打开你要访问的目标网站（Google、ChatGPT 等）。** 如果位置在隐私窗口中正常，说明普通窗口的站点数据或扩展冲突值得继续排查，但这并不能排除目标平台的账号或资格限制。
 - **第七步，回到正常浏览器窗口做最小范围清理。** 只删除发生问题域名的 Cookies 和缓存，然后重启浏览器，其他网站的登录状态可以继续保留。

### 重定向次数过多。

**解决办法：**删除 **无忧行** 的 **控制面板 - 代理策略** 里`google.com`、`openai.com`和`bing.com`等常见的网址的访问策略，关掉浏览器、再次打开浏览器、点开无忧行，然后再次尝试访问。

### 没有显示 New Bing 入口

Bing/Copilot 的入口和功能由微软根据产品上线范围、账户资格、年龄、组织策略及当前服务状态决定；节点连通不代表第三方账户一定具备功能资格。

#### 排查方法

 - 在 Edge 的 InPrivate 窗口开启无忧行，先确认连接本身；
 - 退出登录后对比页面，判断问题更接近连接还是账户；
 - 登录你本人持有、资料真实且符合微软条款的账户；
 - 到微软官方支持页核对当前可用地区和账户要求，并保持国家、电话号码和账户资料真实一致。

### 默认搜索引擎显示为中国大陆版必应

#### 重新配置Edge的默认搜索引擎

在Edge的地址栏内输入`edge://settings/searchEngines` ，点击右上角的`添加/Add`按钮。

```sh
#Search engine
Bing
#Shortcut
bing.com
#URL with %s in place of query
{bing:baseURL}search?q=%s&{bing:cvid}{bing:msb}{google:assistedQueryStats}
```

添加完成后，点击右侧三个点将其设为默认即可。

### 账户和系统地区应保持真实一致

微软账户资料和 Windows 地区应与实际居住地和账户资料一致。连接检查只需按本页步骤进行，地区和定位设置继续保留真实信息。

### 拓展解决方案 3：更换 ISP

如果上述步骤仍无法解决，可以更换网络环境做对照测试，以区分本地网络、组织策略和产品连接问题：

- Wifi换成有线、有线换成Wifi
- 禁止Wifi和有线，使用手机热点
- 在办公室网络环境和家里网络环境切换尝试
- 在自己和同事、同学、朋友的之间的网络环境切换尝试

大体思路就是电信不行就换联通，联通不行就换移动…

以上各解决方案是无忧行团队和用户反复尝试后得到的经验，希望能对您有所帮助。

### Bing 提示“你已达到今天的对话限制，登录以继续你的聊天”

这个提示来自 Bing 的账户或产品限额，不是节点测速结果。请按页面提示等待限额恢复，或到微软账户与官方支持页核对当前资格。

### 在浏览器隐私模式中使用无忧行

 - 在Edge浏览器地址栏内输入 `edge://extensions/`，打开扩展管理界面，找到无忧行点击详细信息
 - 在详细信息页面里选中在InPrivate中允许
 - 点击Edge浏览器右上角三个点，在下拉菜单中选中新建InPrivate窗口
 - 大功告成

### 防火墙保持开启，按最小范围排查

排查期间保持系统防火墙和整体安全等级不变。若公司网络或安全软件阻止扩展连接：

 - 先切换到可信的家庭网络或手机热点做对照测试；
 - 在 Windows 安全中心或 macOS 防火墙日志中确认具体被阻止的应用、域名或端口；
 - 只有在能确认阻断项时，按照系统或组织管理员的要求添加针对浏览器应用的最小例外；
 - 测试结束后撤销临时例外，并在需要时把发生时间、系统、浏览器版本和错误现象发给支持团队。

### 使用 Edge 无痕模式检查 New Bing

如果遇到聊天窗口消失的情况，可以通过如下方式测试：

 - 暂时关闭其他浏览器插件、只保留无忧行，并允许无忧行可以在无痕模式下使用
 - 将无忧行设置为规则模式
 - 关闭本地其他代理软件，如网易UU、讯飞游戏加速器、Clash等软件干扰
 - 打开Edge的无痕模式，输入bing.com。
 - 如果发现有聊天入口，就代表无忧行的new bing解锁成功了。
 - 回到普通版 Edge 如果没有聊天窗口，只清理 `bing.com` 的站点数据，重启 Edge 后再次对比。
 - 如果未登录时有、登录后没有，通常应转向微软账户资格或组织策略排查，并继续使用本人资料真实的账户。
 - 测试期间保持代理软件、节点和账户不变，便于比较结果。
