# 常见问题

这里整理了使用无忧行时常见的几个问题。

### 所有线路都能进行 Gemini、ChatGPT、Claude 等 AI 产品的访问吗？

不是所有线路都适合 AI 产品，按使用方式选择即可：

- 使用浏览器插件访问 ChatGPT、Claude、Grok 等产品时，选择**规则**模式和带 `[AI]` 标注的节点；
- 使用浏览器插件访问 Gemini、AI Studio、NotebookLM 等 Google AI 产品时，选择**全局**模式和合适的节点；
- 使用手机订阅客户端时，选择 `🤖 ChatGPT Group` 分组中的节点。

浏览器插件的具体操作见[如何使用无忧行访问 AI 产品](/guide/chatgpt-access)；订阅服务的具体操作见[如何使用无忧行进行 Vibe Coding](/guide/vibe-coding)。

### 打不开 Gemini、ChatGPT、Claude 等境外的网站了？

请**优化本地网络和浏览器的环境**，按照下面的步骤处理一下，每一步都很重要：

**网络环境**

- **修改 DNS**：把本机/路由器的 DNS 换成国内公共 DNS——最快的方式是直接填阿里 `223.5.5.5` 或腾讯 `119.29.29.29`。想要更安全、能防劫持/污染的**加密 DNS（DoH/DoT）**，请看这篇 👉 [加密 DNS 完全指南](/guide/encrypted-dns)。
- **清理 DNS 缓存**：`Win+R` 输入 `CMD` 回车，再执行 `ipconfig /flushdns`。
- **关闭本地其他代理软件**：如网易UU、讯飞游戏加速器、V2rayN、Clash 等软件干扰。
- 打开 `系统设置` -> `网络和 Internet` -> `代理`，设置：
  - 自动检测设置：关闭
  - 使用设置脚本：关闭
  - 使用代理服务器：关闭

**浏览器环境**

- 升级浏览器至最新版本，清除 Cookies 和缓存并重启浏览器（时间范围选“全部”时会退出各网站的登录，重要账号先确认能重新登录）。
- 升级无忧行至[最新版本](/guide/keep-updated)，并只保留无忧行，暂时禁用其他浏览器插件。
- 把无忧行设为**规则**模式（免费版显示为**开启**）。
- 重启浏览器。

> 能正常访问 ChatGPT 等网站之后，再逐个开启其他插件或软件，排查插件之间的相互影响。

### 为什么 Google、ChatGPT 显示的地理位置与节点服务器不符（区域判定错误）？

**现象原因：**
互联网主流平台（如 Google、OpenAI）不会只看 IP，它们会同时参考 **Cookies**、浏览器缓存、账号行为以及设备指纹来做风控画像。如果同一个账号频繁在不同 IP 或地区之间切换，系统很容易判定为代理或异常登录，进而触发额外验证甚至限制访问。因此上外网时尽量保持节点稳定，避免频繁或跨区切换。

如果你曾在未开启代理的情况下访问过这些服务，或者浏览器缓存中记录了真实的地理位置信息，即便切换了节点，平台仍可能优先读取本地留存的定位数据。频繁在不同节点间切换，甚至可能导致你的账号被系统标记为“异常访问”，影响节点信誉度。

**推荐阅读：** [了解和管理 Google 搜索时的位置信息](https://support.google.com/websearch/answer/179386?hl=zh-Hans)

**排查思路：用无痕模式做一次“纯净测试”**

思路很简单——先用一个没有任何缓存、Cookies 干扰的环境，验证一下节点本身有没有问题；如果在这个干净环境下一切正常，那就说明问题只是出在平时浏览器里残留的旧数据上，清一下就好了。具体步骤如下：

- **第一步，先把浏览器整个关掉。** 不是关标签页，是把浏览器完全退出，确保没有残留进程在后台偷偷加载旧缓存。
- **第二步，打开“无痕 / 隐私模式”窗口。** Windows 下快捷键一般是 `Ctrl + Shift + N`（Edge 是 `Ctrl + Shift + P`），Mac 下是 `Cmd + Shift + N`。这个窗口不会读你平时的 Cookies 和缓存，相当于一个临时的“干净浏览器”。
- **第三步，让无忧行在无痕窗口里也能跑。** 浏览器默认会把所有插件在无痕模式下禁用掉，所以你得手动放行一下：打开扩展管理页（Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`），找到**无忧行**，点**详情**，把**在无痕模式下启用**（Edge 为**在 InPrivate 中允许**）的开关打开。不打开的话，你进了无痕窗口也是裸奔，下面的步骤都白做。
- **第四步，在无痕窗口里打开无忧行，切到全局模式，选一个你要测试的节点。** 节点选好之后就别来回切了，频繁换节点反而容易被目标网站判定异常。
- **第五步，打开目标网站之前，先去 [IP111.cn](https://ip111.cn) 看一眼。** 这一步是为了确认“我以为我连的节点”和“我实际连上的节点”是一致的。如果 IP111 显示的位置和你选的节点对得上，说明代理这边一切正常。
- **第六步，这时再打开你要访问的目标网站（Google、ChatGPT 等）。** 如果位置显示正确了，基本可以确定——问题只是你平时那个浏览器里的旧数据在作祟，不是节点的锅。
- **第七步，回到正常浏览器窗口做一次彻底清理。** 进浏览器设置，清空 Cookies 和缓存（时间范围选“全部”；这会退出你在各网站的登录，重要账号先确认能重新登录），然后把浏览器重启一下。清完之后再访问目标网站，就应该恢复正常了。

### 如何在浏览器的隐私模式里使用无忧行？

Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。找到无忧行并进入**详情**，开启**在无痕模式下启用**（Edge 为**在 InPrivate 中允许**），再打开新的无痕或 InPrivate 窗口。

### 如何使用网络诊断自助检查插件？

使用浏览器插件时，想自己查看无忧行当前的工作情况，可以点击**无忧行图标 → 控制面板 → 网络诊断**。页面会根据检测结果给出下一步，完整说明见[网络诊断](/guide/network-diagnostics)。

### 订阅客户端连不上或不稳定，怎么排查？

按顺序尝试下面的方法，每做完一步就重新测试一次：

1. 先在控制面板的**订阅节点**页确认本月剩余流量；流量用完后订阅连不上属于正常，恢复方式见[流量限制](/abuse/limits)；
2. 重新复制订阅地址，更新客户端里的订阅，再换分组内的其他节点；
3. 把客户端升级到最新版本；
4. Windows 上用管理员身份重新启动客户端；
5. 暂时关闭系统防火墙或安全软件后重试；不建议长期关闭，确认是拦截问题后重新开启，并只为客户端添加放行；
6. 让本地网络改用公共或加密 DNS：运营商默认 DNS 可能被劫持或污染，导致订阅地址、节点域名解析失败；把本机或路由器的 DNS 换成公共 DNS，或更进一步的加密 DNS（DoH/DoT）后再试，解析器与设置方法见[加密 DNS 完全指南](/guide/encrypted-dns)；
7. 客户端设置里如果有 DNS 覆写选项，可以开启后再试一次。

仍未解决时，带上已尝试的步骤[联系支持](/guide/support)。

### 什么时候需要联系支持？

连接类问题可以先按上面的条目自查；自查后仍没有解决，或者不想再继续折腾，随时可以联系客服——带上你试过的步骤和看到的结果，处理起来会更快。

账户、付款或产品服务类的问题，可以直接进入[联系支持](/guide/support)选择对应类别。
