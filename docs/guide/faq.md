# 常见问题

### 所有线路都能进行 Gemini、ChatGPT、Claude 等 AI 产品的访问吗？

并不是所有线路都能使用 AI 产品，请正确操作：
 - 手机订阅 请使用 `🤖 ChatGPT Group 分组`里的节点服务器进行访问Gemini、ChatGPT、Claude 等 AI产品。
 - 浏览器插件 请使用带有`[AI]`标注的节点服务器进行访问Gemini、ChatGPT、Claude 等 AI产品。
 - 谷歌 AI 产品（如 Gemini、AI Studio、NotebookLM 等）需要将代理设置为**全局模式**才能正常访问。

### 打不开 Gemini、ChatGPT、Claude 等境外的网站了？

请**优化本地网络和浏览器的环境**， 按照下面的步骤处理一下，每一步都很重要：

 **网络环境**
  - **修改 DNS**：把路由器和本机的 DNS 改成腾讯或者阿里的公共DNS，推荐搭配一起使用：
    - **腾讯公共 DNS**：[官网地址](https://www.dnspod.cn/products/publicdns#publisDnsStart)（[查看DNS设置帮助](https://cloud.tencent.com/document/product/302/110786)）
      - IPV4 服务器地址：`119.29.29.29` 和 `182.254.116.116`
      - IPV6 服务器地址：`2402:4e00::` 和 `2402:4e00:1::`
    - **阿里公共 DNS**：[官网地址](https://www.alidns.com/)
      - 服务器地址：`223.5.5.5` 和 `223.6.6.6`
      - IPv6地址：`2400:3200::1` 和 `2400:3200:baba::1`
  - **清理DNS缓存**：
    - 点击`开始`->`运行`，输入`CMD`进入命令行模式。
    - 在命令行里输入`ipconfig/flushdns`按回车。
  - **关闭本地其他代理软件**，如网易UU、讯飞游戏加速器、V2rayN、Clash等软件干扰
  - 打开 `系统设置`->`网络和Internet`->`代理` ，设置：
    - 自动检测设置：关闭
    - 使用设置脚本：关闭
    - 使用代理服务器：关闭

 **浏览器环境**
  - 升级浏览器至最新版本，清除所有Cookies和缓存并重启浏览器
  - 升级无忧行至[最新版本](/guide/keep-updated)，并只保留无忧行暂时禁用其他浏览器插件
  - 将无忧行设置为规则模式（免费为开启）
  - 重启浏览器


> 能访问New Bing或者ChatGPT之后，就可以尝试逐个开启其他插件或者软件了，目的是排查插件之间的相互影响。

### 为什么 Google、ChatGPT 显示的地理位置与节点服务器不符（区域判定错误）？

**现象原因：**
互联网主流平台（如 Google、OpenAI）不会只看 IP，它们会同时参考 **Cookies**、浏览器缓存、账号行为以及设备指纹来做风控画像。如果同一个账号频繁在不同 IP 或地区之间切换，系统很容易判定为代理或异常登录，进而触发额外验证甚至限制访问。因此上外网时尽量保持节点稳定，避免频繁或跨区切换。

如果你曾在未开启代理的情况下访问过这些服务，或者浏览器缓存中记录了真实的地理位置信息，即便切换了节点，平台仍可能优先读取本地留存的定位数据。频繁在不同节点间切换，甚至可能导致你的账号被系统标记为“异常访问”，影响节点信誉度。

**推荐阅读：** [了解和管理 Google 搜索时的位置信息](https://support.google.com/websearch/answer/179386?hl=zh-Hans)

**排查思路：用无痕模式做一次"纯净测试"**

思路很简单——先用一个没有任何缓存、Cookies 干扰的环境，验证一下节点本身有没有问题；如果在这个干净环境下一切正常，那就说明问题只是出在平时浏览器里残留的旧数据上，清一下就好了。具体步骤如下：

 - **第一步，先把浏览器整个关掉。** 不是关标签页，是把浏览器完全退出，确保没有残留进程在后台偷偷加载旧缓存。
 - **第二步，打开"无痕 / 隐私模式"窗口。** Windows 下快捷键一般是 `Ctrl + Shift + N`（Edge 是 `Ctrl + Shift + P`），Mac 下是 `Cmd + Shift + N`。这个窗口不会读你平时的 Cookies 和缓存，相当于一个临时的"干净浏览器"。
 - **第三步，让无忧行在无痕窗口里也能跑。** 浏览器默认会把所有插件在无痕模式下禁用掉，所以你得手动放行一下：打开扩展管理页（Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`），找到 **无忧行**，点"详情"，把"**在无痕模式下运行 / Allow in InPrivate**"那个开关打开。不打开的话，你进了无痕窗口也是裸奔，下面的步骤都白做。
 - **第四步，在无痕窗口里打开无忧行，切到"全局模式"，选一个你要测试的节点。** 节点选好之后就别来回切了，频繁换节点反而容易被目标网站判定异常。
 - **第五步，先别急着打开目标网站，先去 [IP111.cn](https://ip111.cn) 看一眼。** 这一步是为了确认"我以为我连的节点"和"我实际连上的节点"是一致的。如果 IP111 显示的位置和你选的节点对得上，说明代理这边一切正常。
 - **第六步，这时再打开你要访问的目标网站（Google、ChatGPT 等）。** 如果位置显示正确了，那就可以 100% 确定——问题真的只是你平时那个浏览器里的旧数据在作祟，不是节点的锅。
 - **第七步，回到正常浏览器窗口做一次彻底清理。** 进浏览器设置，**清空所有 Cookies 和缓存**（时间范围选"全部"），然后把浏览器重启一下。清完之后再访问目标网站，就应该恢复正常了。

### 默认搜索引擎是大陆的必应怎么办？

#### 重新配置Edge的默认搜索引擎

在Edge的地址栏内输入`edge://settings/searchEngines` ，点击右上角的`添加/Add`按钮。

```sh
#Search engine
Bing
#Shortcut
bing.com
#URL with %s in place of query
{bing:baseURL}search?q=%s&{bing:cvid}{bing:msb}{google:assistedQueryStats}
```

添加完成后，点击右侧三个点将其设为默认即可。

### Bing 提示“你已达到今天的对话限制，登录以继续你的聊天”

看到这个提示的时候本质上是你账户的问题，无论你怎么找无忧行沟通技术细节，更换更多服务器节点或者按照上述方法换国家和地区**都没用**了。

**解决方法：**

请使用无忧行的解锁流程，重新注册一个全新的Bing的账户即可。

### 如何在浏览器的隐私模式里使用无忧行？

 - 在Edge浏览器地址栏内输入 `edge://extensions/`，打开扩展管理界面，找到无忧行点击详细信息
 - 在详细信息页面里选中在InPrivate中允许
 - 点击Edge浏览器右上角三个点，在下拉菜单中选中新建InPrivate窗口
 - 大功告成

### 建议关闭防火墙

无忧行会采用特殊端口进行流量的封装、加密和解密，在使用无忧行时建议关闭或者降低网络防火墙的安全等级。

Windows：若要打开或关闭 Microsoft Defender 防火墙，请执行以下操作：

 - 选择"开始"，然后打开"设置"。 在"隐私和安全" 下面，选择"Windows 安全" >"防火墙和网络保护"。 打开 Windows 安全中心设置
 - 选择网络配置文件：域网络、专用网络 或 公用网络。
 - 请将设置切换为"关闭"。

Mac：若要打开或关闭 Mac 防火墙，请执行以下操作：

 - 请选取苹果菜单 苹果菜单 >"系统设置"，在边栏中点按"网络" 网络，然后点按右侧的"防火墙"。
 - 请将设置为关闭状态。

### 如何通过 Edge 无痕模式测试 New Bing 是否解锁成功？

如果遇到聊天窗口消失的情况，可以通过如下方式测试：

 - 暂时关闭其他浏览器插件、只保留无忧行，并允许无忧行可以在无痕模式下使用
 - 将无忧行设置为规则模式
 - 关闭本地其他代理软件，如网易UU、讯飞游戏加速器、Clash等软件干扰
 - 打开Edge的无痕模式，输入bing.com。
 - 如果发现有聊天入口，就代表无忧行的new bing解锁成功了。
 - 回到普通版的Edge如果没有聊天窗口，请清除所有Cookies和缓存，重启Edge再次访问sg.bing.com，看下有没有聊天窗口。
 - 如果未登录的时候有，登录后没有，请在无痕模式下开启无忧行重新注册个新的new bing账户。
 - 不要频繁更换代理软件或者同一个账户一会儿访问国内的必应，一会儿访问海外的new bing
