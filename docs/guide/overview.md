# ✨无忧行概述

无忧行（Jego）是专为 Chrome 和 Edge 设计的免费代理工具，帮助你简单、安全、高效地绕过网络限制（翻墙），访问全球网站。安装轻巧、操作直观，第一次使用也能快速上手。

## 无忧行的两种使用方式

### 一、浏览器插件

浏览器插件直接安装在 Chrome 或 Edge 里，适合在浏览器中访问网站。安装后登录账号，选择**规则**模式和**自动选择**节点，就可以开始使用。

按顺序查看：[安装插件](/guide/installation) → [注册账户](/guide/registration) → [开始使用无忧行](/guide/usage)。

### 二、订阅服务

订阅服务适合在 Windows、macOS、Linux、Android、iPhone 或 iPad 上使用。会员登录控制面板后，进入**订阅节点**复制订阅地址，再把它导入兼容的电脑或手机客户端，浏览器之外的应用也可以使用代理。

按顺序查看：[了解订阅服务](/subscription/) → [按设备选择客户端](/devices/) → [导入和管理订阅](/subscription/management)。

会员价格、有效期和当前权益会直接显示在登录后的控制面板和购买页面，付款前以页面内容为准。

无忧行会跟随浏览器语言显示界面。目前的正式翻译包括：

简体中文、繁體中文（香港）、繁體中文（台灣）、English、العربية、বাংলা、فارسی、Filipino、Français、हिन्दी、Bahasa Indonesia、日本語、한국어、Bahasa Melayu、မြန်မာ、Русский、ไทย、Türkmençe、Українська 和 Tiếng Việt。
