# 节点介绍

代理服务的节点线路，本质上可以按照**流量的入口与出口路径**来区分。理解这个核心逻辑，有助于你根据自己的网络环境选择最合适的线路。我们的节点服务器主要由下列四种方案组合而成。

## <span style="color:red;">先说结论</span>

::: danger 重要提醒
<span style="color:red;">如无特殊需求，首选</span><span style="color:red;">**自动选择**</span><span style="color:red;">。</span>

由于各个地区网络环境的不同，可能不是每个用户都能顺畅地连通每一个节点服务器，当无忧行处于**自动选择**的状态时，程序就会自动选择一个能连通的节点服务器。
:::

## 科普：速度取决于最差的那一段

当你使用无忧行最顶级的线路（Ultra节点）访问一个境外网站（例如 YouTube）的完整路径大致如下：

> 你的设备 → 你的路由器、光猫 → 你的当地运营商（电信/联通/移动） → 国内公网 → 无忧行国内入口服务器 → 专线或 IEPL → 境外出口服务器 → YouTube

无忧行的专线或 IEPL 只负责中间的那一小段**"过境"传输**。而你的整体上网体验，取决于这条链路中**最差的那一段**——这就是木桶效应。

::: warning 举个例子
如果你的本地网络到中国跨海骨干网络入口处的速率本身就不理想，那么从你家到无忧行入口服务器这一段就已经在"堵车"了，我们的专线再快也无济于事。所以在排查网络问题时，请先确认你的本地网络环境是否正常。参考：[优化本地网络和浏览器的环境](/guide/faq#打不开-gemini、chatgpt、claude-等境外的网站了)
:::

## <span style="color:orange;">边缘网络（境外）</span>

<div v-html="edgeSvg"></div>

**原理：** 流量从你的设备出发，直接跨越公共互联网连接到境外服务器，全程走公网，没有任何针对中国大陆网络的特殊优化。

由世界各地的运营商或商家提供的云服务，提供 100Mbps 到 10Gbps 不等的国际网络容量。由于走的是公共互联网，线路质量完全受制于中国大陆与境外之间的跨境公网状况，高峰期或敏感时期容易出现速度下降甚至断连。

::: info 限制说明
无法对身处中国大陆的用户保证速率；

无法对身处中国大陆的用户保证连通性；

身处中国福建、河南、新疆三个地区的用户可能无法使用。
:::

::: tip 适合场景
网络管控宽松时期，或对价格敏感、对稳定性要求不高的普通轻度使用需求。
:::

## <span style="color:blue;">大陆优化线路（境外）</span>

<div v-html="optimizedSvg"></div>

**原理：** 服务器同样位于境外，流量依然需要穿越防火墙出境，但去程和/或回程使用了中国电信 CN2 GIA、联通 AS9929、移动 CMIN2 等**高质量骨干线路**，而非普通公网。

由骨干网络和精品业务网络组成，是中国大陆与全球网络最顶级的承载网络。相比纯直连线路，跨境路由质量更高，延迟更低、稳定性更好，但带宽资源有限，价格通常高于纯直连线路。

::: info 限制说明
无法提供无限量的数据传输；

无法对身处中国大陆的用户保证连通性；

在某些特定的时期，无法对身处中国大陆的用户保证连通性；

身处中国福建、河南、新疆三个地区的用户可能无法使用。
:::

::: tip 适合场景
日常高频使用、视频会议、流媒体等对速度和稳定性有一定要求，但预算有限、无法使用内网专线的用户。
:::

## <span style="color:purple;">大陆专用中转服务器线路</span>

<div v-html="transitSvg"></div>

**原理：** 在中国大陆境内部署一台专门用于中转的服务器作为**入口**，用户的流量先连接到这台境内服务器，再由它转发到境外出口节点。流量的最终出境仍然需要穿越防火墙，但入口段（用户到中转服务器）完全在国内网络内完成，连接质量有保障。

国内接入段稳定，用户到中转入口的延迟低，受本地运营商网络质量影响小。相较于纯直连，在复杂网络环境下连通性通常更好。中转服务器属于额外的基础设施，成本较高，节点数量相对有限。

::: info 限制说明
跨境出口段依然走公网或优化线路，出口稳定性受境外节点和跨境链路质量影响；

依然需要出境流量穿越防火墙，无法做到零过墙风险。
:::

::: tip 适合场景
网络环境较复杂、直连线路经常不稳定的用户，需要更好的入口稳定性。
:::

## <span style="color:green;">IEPL 内网专线</span>

<div v-html="ieplSvg"></div>

**原理：** IEPL（International Ethernet Private Line，国际以太网专线）是运营商级别的**端对端私有网络电路**，通过与中国电信、中国联通、中国移动等运营商合作，在内部骨干网上构建专属通道，流量**完全不经过公共互联网**，也就是说**不需要穿越防火墙（不过墙）**。

这个方案确保了身处中国大陆的用户能够持续享受稳定、高效的全球网络服务。

::: info 优势说明
流量走运营商内网，天然绕开 GFW 审查，理论上最为稳定；

为身处中国大陆的用户提供全天候稳定、高速的网络访问体验；

可以保证身处中国大陆的用户连通性。
:::

::: tip 适合场景
对稳定性和低延迟要求极高的用户，在敏感时期需要保持始终可用的高级用户。
:::

## 综合对比

| 线路类型 | 入口位置 | 是否过墙 | 稳定性 | 速度上限 | 成本 |
|---|---|---|---|---|---|
| 边缘网络（纯海外直连） | 境外 | 是 | 较低 | 高 | 低 |
| 大陆优化线路（精品网） | 境外（精品网） | 是 | 中等 | 中高 | 中 |
| 大陆中转服务器 | 境内中转 | 是 | 较高 | 高 | 高 |
| IEPL 内网专线 | 内网专线 | 否 | 最高 | 高 | 高 |
